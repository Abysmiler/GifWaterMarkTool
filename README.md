# GifWaterMarkTool

基于 Qt6 + ffmpeg 的所见即所得 GIF 水印工具，支持图片水印和文字水印。

## 界面

浅色毛玻璃风格：冷调发光浅底像描图台，控制面板是浮在台面上的**毛玻璃**板（真实背景虚化），强调色取朱砂红，数值用等宽字读数。

- **浮动毛玻璃**：命令条、检视器、状态胶囊都是磨砂玻璃，透出下方模糊的 GIF/台面。
- **常驻检视器**：参数面板固定在右栏，调不透明度/缩放/旋转时台面实时预览。
- **透明棋盘台面**：水印透明区如实呈现，预览框带柔和投影悬浮于发光地面。
- **直接操作**：拖动水印本体移动，拖角把手缩放，顶部把手旋转（文字水印拖角改字号）。
- **盖章导出**：导出成功后台面落下一枚朱砂印。

## 功能

- 图片水印（PNG）和文字水印
- 拖拽调整水印位置，滚轮 / 把手缩放，把手旋转
- 导出参数可调：分辨率、帧率、调色板、抖动算法
- gifsicle 深度优化，文件体积更小
- 水印参数记忆，换 GIF 自动复用

## 技术栈

- Qt 6.5 QML（QtQuick.Controls.Basic + QtQuick.Effects 毛玻璃 + 自绘组件库）
- ffmpeg + gifsicle
- C++17 / CMake

## 构建

```bash
cmake -B build -DCMAKE_PREFIX_PATH=/path/to/Qt/6.5.3/mingw_64
cmake --build build
```
