# GIF 水印工具 UI 重构设计规格

**日期**: 2026-07-05
**状态**: 待审核
**项目**: GifWaterMarkTool

---

## 概述

将当前 GifWaterMarkTool 的窄侧栏滚动布局重构为现代化"工作台式"布局，以匹配用户的实际操作流程：高频操作（选 GIF → 导出）放在最顺手的位置，低频操作（水印参数调节）通过抽屉面板按需展开。

### 设计目标

1. **操作流程优先**：选 GIF 和导出是一等操作，始终可见、触手可及
2. **预览最大化**：水印位置调节需要精确，预览区应占窗口主体
3. **现代扁平视觉**：圆角卡片、柔和阴影、清晰层次、跟随系统亮暗主题
4. **所见即所得**：拖拽水印、滚轮缩放，所有参数变化即时在预览中反映

## 整体布局

```
┌─────────────────────────────────────────────────┐  1200×780（最小 960×600）
│  🔘 选择 GIF    🚀 导出    │    ⚙️ 水印设置      │  顶部操作栏 48px
│                            │                     │  半透明毛玻璃浮层
├─────────────────────────────────────────────────┤
│                                                  │
│              GIF 实时预览（暗色背景）              │  预览区
│         拖拽水印 / 滚轮缩放 / 所见即所得          │  填充剩余高度
│                                                  │
├─────────────────────────────────────────────────┤
│  🎞 my-gif.gif (480×320)  │  💧 logo.png  │  📂  │  底部状态栏 32px
└─────────────────────────────────────────────────┘
```

- 窗口默认 **1200×780**，最小 **960×600**
- 顶部操作栏和底部状态栏为半透明浮层
- 水印设置通过右侧**抽屉面板**滑出（宽 280px），不常驻
- 支持拖拽文件到预览区直接替换

## 模块细节

### 1. 顶部操作栏

```
┌────────────────────────────────────────────────────────────┐
│  📁 选择 GIF          🚀 导出 GIF         │  ⚙️ 水印设置   │
│  [拖拽或点击选择]      [一键导出]          │  [当前: logo]  │
└────────────────────────────────────────────────────────────┘
```

- `选择 GIF` 和 `导出` 视觉突出（填充色 + 大号字号）
- 水印设置按钮显示当前水印文件名，点击弹出右侧抽屉
- 三个操作视觉权重递减：选 GIF > 导出 > 水印设置
- 背景：半透明毛玻璃效果（Fusion 风格下用半透明 + backdrop 近似）

### 2. 预览区

- 深色背景 `#1a1a1e`，预览框居中适配（保持当前缩放逻辑）
- 水印直接拖拽移动、滚轮缩放，所见即所得
- 空状态显示引导文字："拖拽 GIF 或点击上方选择"
- 支持 Drag & Drop 加载文件（保留现有 DropArea 逻辑）

### 3. 底部状态栏

- 左侧：GIF 文件名 + 分辨率 + 帧率
- 中间：水印文件名
- 右侧：导出目录路径，点击可在资源管理器打开
- 细条 32px，纯信息展示

### 4. 水印设置抽屉（右侧滑出，280px）

```

│  ╳ 水印设置                      │
│                                  │

│                                  │
│  📐 缩放                         │
│  ▬▬▬▬▬▬▬○▬▬▬▬▬▬  120%          │

│  👁 透明度                        │
```

- 文字水印独立分区，不启用时内容折叠
- 导出参数也移入抽屉（低频设置），保持顶部栏精简
- 底部"记住参数"开关

### 5. Toast 通知

- 保持当前设计（顶部居中圆角条），视觉微调匹配新风格

## 视觉风格

- **风格**：Qt Quick Controls Fusion，手动亮暗主题
- **亮色主题**：背景 `#f5f5f7`，卡片 `#ffffff`，主文字 `#1f1f1f`，次要文字 `#86868b`
- **暗色主题**：背景 `#1c1c1e`，卡片 `#2c2c2e`，主文字 `#e8e8ea`，次要文字 `#98989d`
- **强调色**：`#3b82f6`（蓝色，按钮/选中态）
- **圆角**：卡片 12px，按钮 8px，输入框 6px
- **间距**：模块间 16px，控件间 8-12px
- **字体**：系统默认（Segoe UI / PingFang SC），操作按钮 14px，说明文字 12px

---

## 文件变更范围

| 文件 | 变更类型 | 说明 |
|------|---------|------|
| `qml/Main.qml` | **重写** | 主布局从 RowLayout 改为 ColumnLayout，实现顶部栏+预览+底部栏 |
| `qml/ParameterPanel.qml` | **重写** | 从独立组件改为抽屉内嵌内容，增加导出参数区 |
| `qml/CanvasPreview.qml` | **小幅调整** | 保持核心逻辑，调整尺寸计算适配新布局 |
| `qml/Toast.qml` | **小幅调整** | 视觉微调匹配新风格 |
| `core/` (C++ 文件) | **不变** | 后端逻辑无需修改 |

---

## 不变更项

- FFmpegRunner / gifprobe / paths 等 C++ 后端
- CMakeLists.txt 构建配置
- 水印记忆（Settings）持久化逻辑
- 导出流程和参数传递
- 所有 PROPERTY / signal / Q_INVOKABLE 接口

---

## 技术注意事项

- Qt 6.5 + QML + Fusion 风格，无额外 UI 库依赖
- 抽屉动画使用 `NumberAnimation` on `x` 或 `translate`，保持 60fps
- 毛玻璃效果：Qt Quick 不支持原生 backdrop-filter，使用半透明 Rectangle + 颜色混合近似
- 保持 `Qt.labs.settings` 持久化逻辑不变
- Drag & Drop 保留现有实现
